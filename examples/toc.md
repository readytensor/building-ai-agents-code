# Contributor guide

[TOC]

Thanks for helping out. This guide covers setup, how we work, and how to get help.

## Getting started

### Install

Clone the repository and install it with `pip install -e .`.

### Run the tests

Run `pytest` from the project folder. Every test should pass before you start.

## Making a change

### Branches

Work on a branch named after the change, such as `fix-table-borders`.

### Pull requests

Describe what changed and why, and link the issue it closes.

## Getting help

Open an issue with a short example that shows the problem.
